**Muse: Text-To-Image Generation via Masked Generative Transformers**

**Abstract:**

The paper presents Muse, a text-to-image Transformer model that achieves state-of-the-art image generation performance while being significantly more efficient than diffusion or autoregressive models. Muse is trained on a masked modeling task in discrete token space, where it predicts randomly masked image tokens given the text embedding extracted from a pre-trained large language model (LLM). The model consists of several sub-models, including a pre-trained T5-XXL LLM, a VQGAN tokenizer, a base masked image model, and a super-resolution model.

**Key Contributions:**

1. **Efficient Text-to-Image Generation:** Muse achieves state-of-the-art image generation performance while being significantly more efficient than diffusion or autoregressive models.
2. **Discrete Token Space:** Muse uses discrete tokens, which allows for more efficient training and inference compared to pixel-space diffusion models.
3. **Parallel Decoding:** Muse uses parallel decoding, which reduces the number of sampling iterations required for inference.
4. **Zero-Shot Image Editing:** Muse enables zero-shot image editing capabilities, including inpainting, outpainting, and mask-free editing.

**Methodology:**

1. **Pre-trained T5-XXL LLM:** The model uses a pre-trained T5-XXL LLM to extract text embeddings.
2. **VQGAN Tokenizer:** The model uses a VQGAN tokenizer to convert images into discrete tokens.
3. **Base Masked Image Model:** The model uses a masked image model to predict masked image tokens given the text embedding and unmasked image tokens.
4. **Super-Resolution Model:** The model uses a super-resolution model to upsample the base latent map to a higher-resolution latent map.

**Results:**

1. **State-of-the-Art Performance:** Muse achieves state-of-the-art image generation performance on the CC3M and COCO datasets.
2. **Efficient Inference:** Muse is significantly faster than diffusion or autoregressive models at inference time.
3. **Zero-Shot Image Editing:** Muse enables zero-shot image editing capabilities, including inpainting, outpainting, and mask-free editing.

**Conclusion:**

Muse is a state-of-the-art text-to-image Transformer model that achieves efficient image generation performance while being more efficient than diffusion or autoregressive models. The model's use of discrete tokens and parallel decoding enables zero-shot image editing capabilities, making it a powerful tool for image generation and editing applications.
